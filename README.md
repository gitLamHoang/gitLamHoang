# Hi, I'm Harvey Phan.

**Stanford CS · Software Engineer Lead, HARP**

Portfolio: **[Harvey's Hub](https://gitlamhoang.github.io)**

I work on navigation and motion control for humanoid robots with the **Humanoid Athletic Robotics Project (HARP)** at Stanford Student Robotics.

## Current work

I lead HARP's [Human Perception & Social Interaction Team](https://github.com/Humanoid-Athletic-Robotics-Project-HARP/social-interaction), which develops software for the Unitree G1.

My contributions focus on:

- **Navigation:** configurable waypoint routes and repeated laps, with manual takeover and runtime safeguards.
- **Motion control:** speed ramping for straight walks and slowdown near the target.
- **Tools:** recording positions and headings from ROS 2 odometry as reusable waypoint routes.
